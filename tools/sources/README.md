# Controlled source refresh

The runnable app uses the reviewed bundled projection; it does not need network access or a private archive. This separate tool creates an **unreviewed candidate**, never replaces the bundled data or frozen cases. It refreshes the 2024 ACS workbooks and group metadata plus four legislative geometries only; participation and program/reference/case data require a separate manual review. Review source terms and the output before any publication or installation. See ../../DATA-NOTICES.md for attribution and the State commercial-use limitation.

Run the commands below from the `tools/sources/` directory.

1. Manually obtain the four State DBEDT workbooks via the URLs in `allowlist.json`, following applicable terms. Place them in a directory named `dbedt_2024_house.xlsx`, `dbedt_2024_senate.xlsx`, `dbedt_2024_state.xlsx`, `dbedt_2024_counties.xlsx`. The tool will not access State servers. The manual import is an operator representation of origin, not cryptographic proof of origin; compare hashes and review differences.
2. Run `python3 acquire.py NEW_CAPTURE_DIRECTORY --manual-workbooks MANUAL_DIRECTORY`. Only eight hardcoded Census URLs in the reviewed allowlist are accessed by HTTPS; redirects are rejected, requests have 45-second timeouts and 10 MB size limits, XLSX expanded bytes are capped, and new directories are exclusive. Failed/missing inputs yield a nonzero result and report. Captures and imported workbooks may have separate reuse terms and should remain outside the public repository until specifically cleared.
3. Run `python3 normalize.py NEW_CAPTURE_DIRECTORY NEW_REVIEW_DIRECTORY`. It rechecks recorded source set, URLs and hashes, runs the retained statistical compiler's strict table/header/label/variable checks and asserts 1,640 rows (20 measures × 82 geographies), and validates all four geometry layers, including exact district-code sets, STATE, LSY, GEOID, polygon types, finite coordinates, and closed rings (51 House and 25 Senate for each vintage). Outputs and hashes are in `review-manifest.json`; timestamps make statistical output hashes vary between captures. The tool will not overwrite an existing destination. The results must be independently reviewed for drift, semantics, geography, terms, and suitability before integration. No source text is executed or treated as instructions. Run Python without `-O`; the compiler relies on assertions.

The URLs and historic source hashes in `allowlist.json` are an explicit 12-input list, not a claim that the whole historical packet can be reconstructed. `matches_historical: false` is expected when a publisher revises an endpoint; no automatic acceptance occurs. No bundled cases are changed. If a source is unavailable, the acquisition report records an error and normalization refuses the incomplete capture; continue using the existing reviewed snapshot pending manual resolution.

`../compile_statistics.py` is the project compiler retained for its reviewed mapping; `normalize.py` invokes only its `compile_observations` function against a temporary capture-specific manifest. Do not invoke the legacy compiler's main routine as a refresh tool.
